# React Notes App 📝

A simple notes application built with React JS that allows users to add notes with a heading and description, view their notes, and delete them when needed.

## ✨ Features
- Add notes using a form
- Enter note heading and description
- Delete notes easily
- Manage data using React Hooks

## 🛠️ Tech Stack
- React JS
- JavaScript
- HTML5, CSS3 and Tailwind
- Vite

## 📚 Concepts Practiced
- React Components
- Props
- useState
- useEffect
- Form Handling
- Event Handling
- Rendering Lists
- Delete Functionality
